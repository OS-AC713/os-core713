Hello! Here you'll learn how to start contributing to the "Core/713" project.

Before you start, you should decide what exactly you want to contribute to the project. We have 5 main branches, but you can also suggest your own:
Code: You will contribute to the code, improving, reviewing, or adding your own features.
Ideas: You will be able to contribute ideas for the project, specifically any areas where it's truly lacking.
Watermark: You will improve the code in terms of jurisdiction if you see any genuine vulnerabilities in the project. We're currently not hiring for this position.
User Experience: You will improve user experience, such as .sh scripts, installers, makefiles, or other features.
Driver Addition: Yes, this is code-related, but it's still important to us.

For other criteria, you can submit them in issues tagged "Contribution."

That's all for now.
